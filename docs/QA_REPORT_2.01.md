# 2.01 验收记录

## 本版修改

旧版自建“收入”大类缺少收支方向时，通用小类的混用历史可能把整个大类推断到支出侧。2.01 保留明确命名的旧自建收入组的收入含义，不重写旧流水。

`js/storage.js` 的兼容顺序为：已有合法方向保持原值；旧预置组保持支出方向；缺少方向且明确名为“收入”的自建组补充收入方向；其它组沿用原推断。名称、成员、经典图标、排序与隐藏项保留，不扫描重写已有明确方向的用户配置。

Android 版本递增为 2.01／102，包名和签名不变。本版不改金额计算或界面布局。此前的首页、基金逐笔纠错、紧凑日历与原生保存保护一并发布。

## 已验证

- 220 项前端回归通过，相关 JavaScript 语法及差异检查通过。
- 合成回归覆盖旧收入组混用小类、原记录不变、图标保留、幂等读取、明确方向不覆盖及旧预置组不按改名重分类。
- 离线 APK 构建成功；实际包内 36 项 JS／CSS 与生产源码相同，首页仅增加既有离线配置引用，离线标记为 true、API 为 null。
- 三份真实旧版备份分别通过 18、30、22 项隔离核验，包括原流水字段和顺序、账户计算、类别身份、图标 SVG、隐藏项、恢复往返、原生提交副本重开以及自动补记去重。必要的收支元数据与原账目分别比较。
- 首份和第三份全部存储原字符串不变；第二份仅类别系统增加收支方向，原记录及其它存储原字符串不变。
- 第二份原有一笔账户引用缺失，保留原账，未猜测修复。第三份未导出账户配置键，旧版与新版实际读取的默认账户相同；不能据此验证未导出的自定义设置。
- 此前 2.00 的浏览器首页日期轴、基金与日历，以及当前小米手机独立副本原生功能已验收；当前手机从 1.99 更新到 2.00 后，应用实际导出的存储原字符串一致。

## 边界

2.01 的类别修复未在每位用户手机实际覆盖安装，不能将隔离核验描述为所有设备已实测；未重新运行整套原生界面验收。应用关闭时不承诺定时后台执行，自动收入和定投在下次打开时检查并补记。尚未公布交易日范围时按既有规则暂停并提示。

升级只安装新 APK，不自动导入备份、不清空类别。备份未包含的本机密码等设备设置不在账本逐键比对范围内。如果设备已运行错误中间版并保存了明确方向，本修复不会擅自覆盖该方向，需单独核对。

主机临时截图、重复 APK、模拟账本、隔离提取代码及构建缓存在发布前清理。原始备份和简要核验记录保存在本机忽略目录，不上传 GitHub。
