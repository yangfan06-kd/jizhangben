# 流水浏览位置验收（2026-10-13）

## 本轮改动

离开流水前保存筛选范围、已加载笔数和滚动位置，再进入相同账本、相同筛选时恢复。范围由账本、日期模式、年月、起止日期、账户、类别和搜索共同决定；今天／本周等相对时期包含当前日期边界，跨天不复用旧范围。筛选刷新或账本重置时清除旧位置。

状态只存在 `uiState` 内存，不新增或修改账本、类别、账户的存储键；不改变每批 100 笔、日期分组、完整匹配集合汇总及特殊收支规则。现有专项页面返回首页规则保持不变。应用重启后从首批开始，不承诺修改／删除流水后仍定位到同一条记录。
