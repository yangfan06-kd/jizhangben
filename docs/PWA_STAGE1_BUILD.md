# 苹果离线网页版：阶段 1 独立构建与入口原型

日期：2026-11-10。阶段 1 已完成；仍是本机原型，未部署、未安装手机。

## 本轮交付

- `pwa/build.cjs`：独立允许列表构建、输入路径/链接检查、页面引用检查、资源摘要及完整产物替换。失败不覆盖上一次完整产物。
- `pwa/public-files.json`：额外资源清单；原页面及 35 个业务脚本仍采用阶段 0 文件边界，不整目录复制。
- `pwa/icons/`：192、512、180 像素 PNG，沿用原 favicon 图形，没有修改类别图标。
- `pwa/preview.css`、`pwa/install.html`：仅在网页产物中使用的安全区补充、原型状态说明和中文桌面使用步骤。
- `pwa/preview-server.cjs`：固定本机预览服务，只提供专用产物，支持根路径与 `/ledger-preview/` 子路径。
- `package.json`：新增 `pwa:build`、`pwa:preview`、`pwa:test` 三条命令；原有命令不变。
- `tests/pwa-build.test.cjs`：发布边界及失败保留等自动检查。

产物位于 `output/pwa-dist/`，共 46 个文件。生成安装清单、中文名称、相对路径的独立窗口入口和业务启动前的离线配置。页面原型明确显示尚未支持离线打开；没有注册 Service Worker。
