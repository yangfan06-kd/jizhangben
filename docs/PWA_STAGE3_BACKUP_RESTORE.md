# 苹果离线网页版：阶段 3 备份、恢复与风险提示

日期：2026-11-12。状态：本批开发及 Windows 检查完成；iPhone 文件保存与系统分享待真机验收。没有安装手机、发布站点或推送 GitHub。使用隔离浏览器上下文和合成账本，未读取、替换真实用户账本。

## 本批交付

独立存储预览新增备份准备、文件保存/分享/下载选择、持久操作状态、一周后提醒及 JSON 恢复预览。备份格式仍为现有 `jizhangben-backup` 版本 3，不增加安卓无法识别的账本键；程序的存储结构版本未变。

当前独立预览共 51 个允许文件，普通原型仍为 46 个文件。网页尚未有 Service Worker，不能断网冷启动。此批本机验证通过不能视为 iPhone 已正式可用。

## 改动位置

- `pwa/backup.js`：PWA 专用界面和控制器。在设置的备份区添加保存方式、持续显示的状态和恢复预览；使用文本节点展示文件名与账本名，不将外部文件内容作为 HTML 插入。
- `pwa/preview.css`：仅备份区的克制排版，按钮不小于 44 像素，文字使用相对字号，允许换行。首页显示可忽略提醒，设置页不重复占用提醒位置。
- `pwa/app-storage.js`：提供读取数据库已提交快照的备份入口；保存及启动事件用于更新提醒。缺少备份脚本时停止启动，避免误走普通浏览器导出分支。
- `pwa/management-storage.js`：恢复委托到预览；最终替换仍使用既有原子事务。预览后本页又有保存时要求重新核对，另一窗口已更新时拒绝旧页覆盖。
- `pwa/fund-storage.js`：准备文件、读取备份或恢复期间暂缓自动补记，结束后再按原规则处理。
- `js/backup.js`：提取不修改源快照的共享备份生成函数，保留安卓保存桥接、原字段和原格式；文件读取中断会结束等待。只在存在 PWA 控制器时委托新入口。
- `pwa/build.cjs`、`pwa/public-files.json`：备份脚本只加入独立存储预览，位于管理模块之后、应用启动之前。
- `tests/backup.test.cjs`、`tests/pwa-backup-browser.js`、`tests/pwa-backup-interop-browser.js`：补充格式保留、真实文件下载重选恢复和故障检查。管理回归的恢复助手更新为先核对预览再确认。

修改前 12 个文件、副本哈希与完整未提交差异保存在 `backups/pwa-stage3-before-20261112/`。原有未提交修改保留；本批未更改用户图标资源、类别默认值、Android 包名、签名、正式 APK 或现有财务规则。

## 文件操作状态

| 操作 | 显示结果与确认边界 |
| --- | --- |
| 准备备份 | 读取数据库最新已提交快照，显示文件名、数量和准备时间。尚未发起文件保存，不包含未保存草稿 |
| 保存文件 | 仅在浏览器提供文件选择接口时显示；依次等待写入、关闭及读回比对通过，才标记“已写入并核对” |
| 分享备份 | 仅在支持文件分享时显示；系统接口完成后标记“已交给系统分享，尚未确认保存”，不推断已保存到“文件” |
| 下载备份 | 标记“已发起下载，尚未确认保存”；保留对象地址一段时间供浏览器处理，不把链接点击当作落盘成功 |
| 用户核对文件 | 下载或分享后可主动点击“我已在文件中确认备份”，记录为“由你确认”，与程序读回核对分开 |
| 取消/失败 | 记录取消或未完成，不自动转而发起另一种文件操作，不改变账本 |

准备好的快照包含准备时的已保存内容；之后新增账目需重新准备。备份按钮不会持久保存整份 JSON 到 localStorage。操作状态、确认时间和提醒偏好使用独立的 `ledger_pwa_backup_status_v1` 本机偏好，不进入账本事务或导出文件；偏好写入失败时提示时间未能可靠记录，不阻止实际文件保存。

未确认文件备份的非空账本会显示提醒；用户可延后一周。已经确认备份且尚无新保存时不提醒，有新保存也不会在确认后七天内反复打扰。空账本不提醒。清除网站数据、删除网页应用或换机可能影响账目；持久存储不能替代独立文件备份，也不承诺自动保存到云端。

## 恢复保护

1. 先读文件并校验既有格式，再展示文件内账本、已保存账户、流水、大/小类、自定义图标和隐藏项数量，以及各账本日期范围。预览不为了计算金额临时改变当前类别或收支定义。
2. 取消预览或最后确认均不写入；损坏、未知键、未来格式版本或文件读取中断不产生可恢复预览。慢速旧读取不能覆盖后一次文件选择。
3. 确认替换前再次检查数据版本。预览后本页保存过数据则要求重新预览；另一窗口先保存则拒绝旧页覆盖，保留预览和当前账本。
4. 恢复事务失败时完整回滚，预览保留可重试；成功后才重置输入并刷新账本。JSON 仍为整份替换，CSV 仍按原方式新建账本，二者不混淆。
5. 密码、隐私隐藏及文件操作偏好继续与账本分离，恢复不替换这些设备设置。备份含原始账目，不因界面隐藏金额而删去账目。

**实际文件检查**：Edge/WebKit 真正触发浏览器下载，把合成 JSON 保存到本机证据目录，再通过文件输入控件选择该文件，读取并恢复；逐键核对流水、账户、类别、图标、排序及隐藏项。文件不是用测试代码重新拼接后冒充下载文件。

**接口模拟检查**：系统文件选择器和系统分享没有在真实 iPhone 或真实系统弹窗上操作。通过受控接口模拟写入/关闭/读回、取消、配额不足、内容不一致和分享成功/取消，验证状态与失败分支；这不等于原生文件选择器已验收。恢复故障使用真实 IndexedDB 中途 abort，未真的填满磁盘。

**安卓互通边界**：在普通浏览器中运行相同安卓网页业务脚本，模拟保存桥接返回文件内容，再由 PWA 恢复；反向使用 PWA 实际下载文件交给普通业务分支恢复并逐键比对。验证的是代码和备份格式契约，没有操作 Android 真机 SQLite 或手机文件管理器。

PWA 备份检查没有运行异常或意外 API/第三方请求。320 像素宽、根字号 24 像素的预览未横向溢出，恢复按钮不小于 44 像素；已查看 Edge/WebKit 截图。原有隐私隐藏和其他记账检查通过。真实 iPhone 的微信转 Safari、分享“存储到文件”、文件重选、中文键盘、安全区域、桌面独立入口及系统数据回收仍待借设备后验证。

证据位于 `output/playwright/pwa-stage3/`：下载后的合成 JSON、界面截图、各组原始结果和提取 JSON、回归/构建日志、Android 包检查及源文件保护报告。这些文件不进入发布产物。

## 浏览器接口依据

- [文件保存选择器](https://developer.mozilla.org/en-US/docs/Web/API/Window/showSaveFilePicker)：需要安全上下文和用户激活，不能假设所有浏览器都提供。
- [创建可写文件流](https://developer.mozilla.org/en-US/docs/Web/API/FileSystemFileHandle/createWritable)：等待关闭后再进行读回核对。
- [系统分享接口](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share)：Promise 完成的含义因平台而异，不能代替用户文件落盘确认。
