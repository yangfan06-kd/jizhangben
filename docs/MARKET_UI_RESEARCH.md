# 记账 App 界面调研与本项目取舍（2026-09-18）

## 范围与证据口径

用户希望参考下载量大的记账 App，并特别研究姐姐正在使用的“女生记账”。本次查看应用商店公开页面、开发者帮助页，以及用户提供的实际手机截图。没有登录其他 App、抓取私人数据或反编译安装包。

“下载最多”没有统一的跨商店公开榜单。[小米应用商店记账分类页](https://r.app.xiaomi.com/catTopList/204)显示的是该商店的**分类排行**，没有累计下载量；网页检索结果也可能有缓存延迟。[Google Play](https://play.google.com/store/apps/details?id=com.monefy.app.lite)显示的 `10M+` 是该平台的安装量区间，不是精确下载量，也不能与小米榜单直接比较。以下仅用两种可核实的口径挑选高曝光样本，不宣称它们是全市场下载量前几名。数据与页面核对日：2026-09-18。

界面细节的证据分为三类：**用户截图**可直接观察那一屏；**官方帮助页**可核实操作流程；**商店描述**只能核实开发者宣称的功能，不能由此推断每一屏的实际布局。

## 从对照得到的界面原则

1. **“快”首先是少做决定。** 普通支出默认当前类型、今天和上次使用的账户；用户只需选分类、填金额、保存。默认值必须可见可改。用真机任务测试记录实际点击次数与误操作，不照抄商店宣传的“3 秒”。
2. **常用项直接出现，低频项有明确入口。** 前 4–6 个常用类别可一眼看到；完整类别与自定义放在“全部分类”。押金、借贷、代付等保留在“更多类型”，选中后再出现关联字段。
3. **录入、看流水、看统计各有主屏。** “女生记账”的分类网格对录入有效；随手记的总览更适合看账；Money Manager 的账户清晰度对余额核对重要。不要把三套信息合并成一屏。
4. **图标加文字，视觉服务操作。** 自绘一致的图标，不复制竞品素材；没有合适图标的自定义分类先用文字与通用占位。主题色由本项目确定，姐姐偏好的是清楚的分区与路径，不等于必须粉色。
5. **现有财务口径不可为了简化界面而消失。** 转账不算收入或支出；押金全退不计收支，少退差额计支出。录入页可折叠字段，保存前后的解释和明细关联仍必须可追溯。
6. **普适性比模仿单个 App 更重要。** “女生记账”是姐姐偏好的流程样本，不是目标用户限定。用中性的配色、文字和图标；预置类别覆盖常见生活场景，同时允许用户调整。首次使用者即使没有历史数据，也应看懂如何建账、记账、查看结果。
7. **易上手不等于单纯更快。** 常见动作能被发现，按钮用日常语言，默认值能看见，保存或出错后有明确反馈，也能返回修改。用第一次接触项目的家人完成任务来检验，而不只看熟练用户的点击速度。

## 对本项目的实际决定

- **首要屏幕**：独立快速记账页。常用类别图标与名称、类型切换、可见的默认账户/日期、金额和唯一保存按钮；系统键盘先行，真机确认遮挡后才决定是否做应用内键盘。
- **次要屏幕**：流水为默认落地页，一张本月摘要卡加最近账目；报表与账户各自独立。搜索/筛选按需展开。
- **发布顺序**：先验证已发给家人的调试 APK 如何备份、升级和保留数据，再做 UI 原型；试用同时覆盖首次使用者和已有账目的使用者，完成首次进入、普通支出、转账、押金、找账任务，对照是否需要提示、点击数、用时、错误与主观清晰度。
- **暂缓**：皮肤、贴纸、拍照、自动识别、预算、云同步。它们可能有价值，但不解决当前“页面拥挤、记账步骤长”的反馈。
