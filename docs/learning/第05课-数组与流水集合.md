# 数组与流水集合

日期：2026-10-18。本节承接对象初识，属于路线第 05 课的基础部分；条件循环、引用复制与复杂集合操作尚需后续学习。

## 作用与结构

对象组织一笔账的不同属性，数组组织多笔记录。下面仅为教学用虚构数据：

```js
const records = [
  { id: 101, type: "支出", amountCents: 1800, category: "交通" },
  { id: 102, type: "支出", amountCents: 2500, category: "餐饮" }
];
```

外层方括号表示数组，里面每个花括号包住一个记录对象。逗号分隔不同记录。

## 找到记录

```js
records[0];               // 第一笔记录对象
records[1].category;      // 第二笔的类别：餐饮
records.length;           // 记录数量：2
```

索引从 0 开始；索引是当前位置，id 是记录身份，两者不同。筛选和排序后位置可能变化，不能把索引当成永久身份。数组顺序也不等于日期顺序，页面可能另作筛选或排序。

## 添加记录

```js
const newRecord = {
  id: 103,
  type: "支出",
  amountCents: 600,
  category: "餐饮"
};

records.push(newRecord);
```

push 把一笔记录追加到数组末尾，原先两笔仍保留。这里只修改程序内存，不能把 push 本身称为数据库保存。

## 对应实际代码

js/state.js 的 dataState 对象中有 records: []。它表示运行状态中起初有一个空记录数组，之后由加载等流程填充，并非启动时清空数据库。

js/record-form.js 的本地新增分支有 dataState.records.push(localRecord)，后续还有保存、失败恢复等逻辑。本节只追踪集合变化，不展开完整保存流程。

读取过程：dataState.records 取出状态对象里的记录数组；[0] 取数组第一项；.amountCents 取这一笔对象内的金额。

## 练习与记录

示例原来有两笔，执行上述 push 后，records.length 是多少？怎样访问第三笔记录的 amountCents？允许自然语言说明，不要求背语法。

用户回答数量为 3，并写出 `records[2].amountCent`。数量和从 0 开始的索引正确；字段名为 `amountCents`，已轻量纠正后继续学习。
