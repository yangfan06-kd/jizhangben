## 已讲函数

`toCents(value)` 接收金额，转换为整数分并通过 return 返回。调用 `const result = toCents("8.25")` 后 result 为数字 825，单位为分。返回数值与写入数据库是两件事。

用户已正确辨认传入金额，结果多写一位，已纠正；不反复检查同一笔误。

## 为什么需要对象

一笔账包含类型、金额、类别、账户、日期、备注。对象用一组属性把这些信息放在一起。以下仅是教学用虚构对象，沿用真实字段名，省略生产代码中的其他字段：

```js
const record = {
  id: 101,
  type: "支出",
  amountCents: 1250,
  category: "餐饮",
  account: "demo-wechat",
  note: "午饭",
  date: "2026-10-18"
};
```

`record` 是变量名，花括号内是对象属性。冒号左侧为属性名，右侧为值；逗号分开不同属性。类型与类别分别是“支出”和“餐饮”。account 保存账户标识，这里 demo-wechat 只是虚构标识，不是真实用户账户，也不是账户名称。程序通过标识查找对应账户名称。

## 读取与修改

```js
record.amountCents;          // 1250
record.category;             // "餐饮"
record.note = "和同学吃午饭";
```

点号表示访问这个对象的属性。最后一句改的是运行中的对象，不代表数据库已经提交。const 限制 record 重新指向另一个值，不会自动锁住对象内部属性；引用与复制留待后续对象课深入。

## 实际代码位置与作用

阅读 `js/record-form.js` 的 handleSave 中 `const localRecord = { ... }`。真实代码先读取输入、转换金额并检查，再把值放入同一对象，供后续保存和展示使用。

例如 `amountCents: amountCents` 左侧是对象内属性名，右侧是前面算好的变量；同名并不代表两次转换。真实对象还保留 amount 等兼容字段，以及押金、借贷等业务关联，本节不展开。

主线：读取输入 → 检查与转换 → 组成记录对象 → 执行保存 → 更新显示。本节只解释组成对象的部分，不声称创建对象就已完成持久保存。
