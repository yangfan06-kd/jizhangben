# 第 02 课：变量与金额类型

状态：2026-10-18 开始讲解，用户综合练习待完成。

## 本课目标

理解程序怎样暂存输入，以及“显示出来的数字文字”和“能参与金额运算的数字”的区别。结合键盘输入与金额合计说明用途，不逐词考核语法。

## 变量是给程序中的值起名字

以下是缩小后的教学例子，不是生产文件中的完整保存函数：

```js
const amountText = "12.50";
const amount = Number(amountText);
```

amountText 保存文字“12.50”，amount 保存转换得到的数字 12.5。变量名帮助后面的代码继续使用这些值；给变量赋值，不等于已经把数据保存进数据库。

const 声明的变量不能再次赋予另一个值；需要重新赋值时使用 let。例如项目在 js/record-keyboard.js 中使用 let 保存持续变化的键盘表达式。对象内容与 const 的关系留到对象课程解释。

## 文字与数字的用途不同

| 表达式 | 结果 | 场景 |
| --- | --- | --- |
| `"1" + "2"` | `"12"` | 将连续按下的数字拼成输入内容 |
| `1 + 2` | `3` | 对金额或数量求和 |
| `"12.50" + "3.50"` | `"12.503.50"` | 两段文字拼接，不是金额合计 |
| `Number("12.50") + Number("3.50")` | `16` | 将文字转换后进行数值计算 |

引号中的内容属于字符串，JavaScript 的一种数据类型。没有引号的数值属于 number 类型。Number 是 JavaScript 自带的数值转换函数。

字符串拼接本身有实际用途。项目的 appendRecordKeyboardDigit 会把现有表达式与新按下的数字拼起来，所以先按 1 再按 2 得到输入“12”；合计两笔账目时才需要按数字求和。转换时机由业务含义决定。

## 本项目的金额工具

阅读入口：js/helpers.js 的 toCents，以及 js/record-form.js 的 handleSave。

```js
toCents("12.50"); // 1250，单位是分
```

toCents 是本项目编写的函数，内部先用 Number 转为数值，再将元换成整数分；本课先理解用途，完整函数、有效数字判断及返回语法在后续课程拆解。

在 handleSave 中，金额来自 recordAmountValue（键盘表达式计算结果）或兼容表单解析，再通过 toCents 得到 amountCents。实际流程有表达式解析与输入校验，教学例子省略这些分支；不能把 Number 转换或 toCents 的默认返回值当成全部业务校验。

```text
用户输入／键盘表达式
        ↓ 解析并校验
元为单位的数值
        ↓ toCents
整数分，例如 12.50 元 → 1250 分
        ↓
后续保存与账务计算
```

核心账务计算采用整数分，减少直接累计小数带来的误差。小数精度和旧 amount 字段兼容在后续金额课程细讲。

## 变量在项目中的不同用途

- recordKeyboardExpression：当前正在输入的表达式，字符串。
- recordKeyboardVisible：当前是否显示键盘，true／false，属于布尔值。
- amountCents：一笔金额换成分后的数值。

这几个例子说明变量可以记录输入、金额或界面状态，并非所有变量都需要持久化。
