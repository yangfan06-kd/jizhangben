# 更新与备份

1. 在旧版“设置”点击“导出备份”，到手机文件管理的“下载”确认最新 JSON 文件实际存在。备份包含私人账目，请妥善保存。
2. 打开新版 APK，选择安装或更新。不要卸载旧 App，不要清除应用数据。同包名、同签名、递增版本号才可覆盖升级。
3. 打开应用，检查账本、最近及较早流水、账户、类别图标、顺序与隐藏项；可再导出一份，与更新前备份核对。
4. 只有需要恢复时才使用“导入备份”。完整 JSON 导入经用户确认后会替换当前账本；普通 APK 更新不会执行导入。不要把 CSV 当成包含全部类别设置的完整备份。

2.01 的三份真实旧备份已做隔离校验，具体结果和未覆盖范围见 [验收记录](QA_REPORT_2.01.md)。这是数据样本验证，不能替代每台手机的实际升级检查。用户原文件未被修改，真实备份不上传 GitHub。

旧版缺少收入／支出方向的大类，可能补充必要的方向字段；原类别名称、图标、成员、排序、隐藏项和旧流水保留。已有明确方向不会被批量重置。发现差异时先保留更新前后两份备份，不自行卸载重装。
