## 改动

- `js/charts.js`：首页趋势最多四个均匀日期标签，首日及当天保留，曲线仍包含全部逐日数据。避免月中最后两个标签挤在一起。
- `index.html`、`css/style.css`：期间收支放在最近流水与本月趋势之间，用“查看”和箭头表达可点击。
- `js/investment-plans.js`：基金详情资金记录旁新增“更正”，进入独立页预填金额、账户、日期。投资和定投均可更正某笔投入，取出可更正到账金额及账户；不改变后续计划金额／频率。
- 更正投入保留记录编号及原定投发生项标识；重新派生总投入，不把增减重复写入建账前原始成本。投入仍是账户间转账，不算消费。
- 可撤销误记投入，原定投去重标记保留，不在下次启动重新补回。暂停后续定投另设勾选，默认不勾选；暂停也改用失败可恢复的统一提交。
- 已全部赎回时，按累计取出减总投入重新计算最终盈亏；原结算 ID 尽量保留，零差额时移除结算，重新出现非零差额再生成结算。基金专属账户余额相应归零。部分赎回继续保持本金中性。
- 已结清的到账记录可更正，暂不撤销；因为旧记录没有可靠区分最终／部分赎回，直接移除到账却保留“已结清”会误算，需另做明确的“撤销全部赎回”流程才可开放。
- 更正日志只在用户保存／撤销时追加到该基金，保留更正前记录与结算快照，随原备份格式一起导出。不在启动时增加或重写审计记录。
- `fundPersistState`：原生存储中流水与基金计划同一事务提交（涉及账户创建／删除时账户也纳入）；失败恢复内存与原值。浏览器沿用可回滚的逐项存储，不能宣称浏览器跨键也具有原生事务保证。
- `js/compact-calendar.js`：日期／月份统一应用内选择，正常宽度最多 360px，最大高度为视口的 80% 且不超过 520px；大字／矮屏可内部滚动。年月可直接选择，必填不可清空，选填可清空。确定才派发原字段 input／change，取消／遮罩／返回只关闭；原生字段类型和业务监听不变。日历开启时隔离背景焦点，关闭恢复。

交互语义参考 [Actual Budget 的计划管理](https://actualbudget.org/docs/schedules/) 对未来计划、单笔交易与跳过发生项的区分。本应用保留原交易日表、未知年份暂停补记和原基金结算口径，不照搬外部财务算法。
