# 苹果离线网页版：阶段 4 离线与更新保护

实施跨 2026-11-12 至 13 日。状态：Windows 本机开发检查完成；未部署、未推送、未安装手机，真实 iPhone 尚未验收。只使用隔离浏览器和合成账本。

## 实现与文件边界

- `pwa/sw-template.js`：构建时注入资源摘要，只缓存允许的程序文件。安装过程中完整下载、核对 SHA-256，并保存完成标记；失败删除本次不完整缓存，保留已有版本。程序缓存代码不访问账本数据库或设备偏好。
- `pwa/build.cjs`：从源文件和缓存模板生成稳定版本号；资源地址携带版本，脚本与样式增加完整性属性，避免新 HTML 混用旧文件。资源加载失败时显示中文阻断入口，保留网站数据。
- `pwa/offline.js`：显示实际离线核对状态、联网修复和新版本提示。新版本完整下载后等待用户操作；新记账草稿先写入并读回核对，不能保存草稿则拒绝更新。原流水编辑、其他未完成表单和正在保存/导入时不切换。
- `pwa/app-storage.js`：切换程序时暂时阻止新的账本操作；没有进行数据库结构迁移或重建。该限制只在明确更新时生效，失败会解除。
- `pwa/preview.css`：离线状态使用可展开的小区域，所有应用文案为中文。普通原型没有加载离线控制器。
- 测试脚本 `tests/pwa-offline-browser.js`、`tests/prepare-pwa-offline.cjs`、`tests/pwa-offline-server.cjs`：隔离构建 A/B/C，测试服务仅监听本机 4177/4178，包含受控下载失败和错误资源；不进入发布产物。

离线预览共 53 个允许文件，缓存其中 52 个程序文件及一个内部完成清单；Service Worker 自身由浏览器管理。普通原型仍为 46 个文件，无 Service Worker。构建的 `offlineReady:false` 表示构建不能代替设备缓存确认，页面运行后核对成功才显示可离线使用。

更新按版本读取资源，旧页面继续使用原版本缓存。若旧文件缺失，只接受摘要相同的网络修复，拒绝用不同内容填充旧缓存。只在单窗口且当前版本已使用的条件下清理更早的本作用域程序缓存，保留当前与最近一个旧版本；其他应用缓存不清理。接口、未知路径、账本备份和数据库不属于程序缓存。

## 更新保护

1. 不自动调用更新后的页面刷新。初次缓存激活可以接管页面，但不会因此清空输入。
2. 多窗口时拒绝强制激活，要求关闭其他记账窗口。即使其他旧页面仍存在，版本地址也不会让其静默混用新文件。
3. 原流水编辑和其他未完成设置要求先保存或取消。新记账金额、表达式、类别、账户和备注按既有草稿格式核对保存，更新后沿用原“是否恢复”交互，草稿不会变成流水。
4. 保存、文件处理和导入过程中不能更新。真正切换时冻结新交互，避免检查之后又开始一笔写入。
5. 更新下载中断或摘要不符时，旧版仍可使用；程序回退保护不等于任意数据库版本回退。本批没有更改账本结构版本或财务规则。
