## 自动化问题与处理

1. 首次 AAPT2 资源链接异常；相同源码在获准的正常本机环境重试构建成功，没有修改生产 Gradle 或资源解决。
2. 首次安装被手机限制，用户明确允许后重试成功；后续覆盖安装成功。
3. 初轮交互脚本先切换页面再重置表单，重置收起了键盘；夹具账户也不是默认微信。改为先重置、显式选择合成账户、再进入记账页，并增加键盘可见的前置断言。原失败报告保留，未改业务。
4. 排序初测在类别页恢复滚动尚未完成时就定位触点。定点复核先等待实际绘制／恢复，再滚动到目标，并断言 `elementFromPoint` 命中正确小类后才注入触摸，完整拖放通过。没有绕过长按门槛或直接调用重排函数冒充交互成功。
