# 2.05：备注输入留白与连续记账选择保留

日期：2026-10-29。正式包 `com.jizhangben.app`，版本 2.05／106。

## 修改范围

- `css/style.css`、`js/view.js`：仅记一笔页面取消已隐藏底部导航所占的留白，减少表单底部空位；空反馈不占高度。自定义金额键盘继续按实际高度预留空间，其它页面不变。
- `js/record-keyboard.js`：备注等文字框获得焦点时收起金额键盘；系统可视窗口变化时，仅在当前输入框被遮挡时作最小滚动，不进行居中跳转，不拦截正常浏览。
- `js/record-form.js`：成功新增或编辑后沿用当前类型、有效类别和账户，转账保留双方账户；清空金额、备注、编辑状态及原押金等结算关联。普通重置仍保留原逻辑，失败不清空输入，不将支出类别带到收入侧。此项用于当前记账页连续录入，不新增跨重启的默认偏好。
- 未修改存储结构、升级迁移、历史类别、图标、财务计算或原生返回规则。未推送 GitHub。
