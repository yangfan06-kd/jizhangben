# 首页阶段 1 实施与验证（2026-10-15）

## 范围与结果

本轮将已确认的首页层级落到生产展示层，仅修改 `css/style.css`，没有复制独立原型的示例类别或业务实现。类别、名称、图标编号、排序、隐藏项、记录、账户、财务公式、存储键、返回与离线代码保持本轮开始时的内容。

开始前保存当前样式、HTML 与 140 项源文件／配置的 SHA-256，避免用 Git HEAD 覆盖已有未提交工作。结束核对仅样式文件改变；此证据针对电脑源文件，不表示已检查手机私有账本。

## 具体改动

- 首页标题采用紧凑字号，账本选择与小眼睛改为静态网格排版，避免绝对定位挤压；二者保持至少 44px 高命中区域。账本选项与切换流程不变。
- 账户、报表、预算、基金沿用四个入口，减去独立白框与阴影；使用少量有色原图标，保留中文标签，按钮至少 48px 高。
- 结余摘要采用已有浅绿实色，统一月收支、净资产的文字与数字层级；取消多余横线，不改变统计口径。
- 四条期间行继续纵向排列，每行支出在上、收入在下，默认字号下保持约 64px 高。宽度不足或文字放大时自然折行；收支标签不消失，长金额不截尾。
- 新增负债改为标签与金额一行；趋势图保留原数据、图例和绘制代码。
- 底栏保留流水、居中记一笔、设置，中央加号从 44px 调至 54px，按钮至少 52px 高，减少边框与阴影。底部滚动留白按字号及既有安全区变量计算。
- 提取少量 `--home-*` 字号、间距与颜色变量，删除一组重复首页覆盖；未清理其他页面的历史样式。

## 浏览器证据

隔离本机来源 `http://127.0.0.1:8771/`，Edge，使用虚构的生活账本、微信及银行卡账户。样例本月收入 3,200 元、支出 144.50 元、结余 3,055.50 元，不代表用户金额。

35 项检查通过，包括：

- 首页四个期间及支出／收入顺序，月结余独立预期。
- 隐私对结余、月收支、净资产、期间金额及负债的现有遮挡有效。
- 账本选择展开，四个快捷入口、记一笔和四个期间流水跳转正常。
- 320、360、390、412、680px 宽度，默认、130%、200% 根字号，共 15 组排版检查；横向不溢出，长金额不截尾，命中区域与底部留白符合本轮规则。
- 568×320 横屏末尾内容能滚动至底栏上方；空账本仍有四行零金额。
- 320px／200% 下额外检查超长账本名、负收入及极长金额；名称可省略，金额允许换行，未改变其数值。
- 页面浏览没有改写合成账目的内存数据；持久化存储只排除隐私开关的预期写入，其余业务项前后一致。

首轮排版测量虽无溢出，截图仍发现大字下金额列过窄，改为可换行的弹性布局后确认。验证脚本曾被横屏检查的字号复位影响，已显式恢复 200% 后重跑，不将普通字号结果当作大字证据。

本机产物位于 `output/playwright/stage1/`：`home-before.png`、`home-after.png`、`home-private.png`、`home-large.png`、`home-periods-large.png`、`home-empty.png`、`review-final.json`、`npm-test.log`、`before-files.json`。不将这些本机合成数据自动推送。
