## 可选的清理影响实验

仅在设备主人明确同意、测试来源没有真实账目、且 JSON 已在另一位置核对可恢复后进行。一次只做一种操作：移除主屏幕图标、删除网页应用、仅清理该测试网站数据；分别记录系统提示与数据结果。

**不要清理 Safari 全部历史或全部网站数据，不要删除设备主人的其他应用或文件。** 未获同意时跳过此组，保留“未测”状态。清理的实际影响需要记录 iOS 版本和具体系统操作，不能凭 Windows 模拟得出结论。
