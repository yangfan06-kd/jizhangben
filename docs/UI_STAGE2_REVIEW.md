## 改动与边界

| 文件 | 实施内容 |
| --- | --- |
| `css/style.css` | 仅在记一笔内统一普通／借贷／代付／报销／退款／押金等字段的轻底线，标签 13px、内容 14px；选项至少 44px、有限高度滚动；用 rem 支持文字放大。保持类型横向标签与细底线、金额第一行和原有布局。长金额换行而非省略尾数；橙色确认键改深色字；隐私模式隐藏计算过程。 |
| `js/record-form.js` | 缺项或不合法输入在对应字段下提示并定位；关联选择器定位后由用户展开。保留金额、计算式和其他输入，不触及业务写入；修正输入、再次提交、重置或切换类型时清除旧反馈。保留其他无障碍说明，清除残留的空状态消息样式。 |
| `js/record-keyboard.js` | 无效计算式使用同一字段反馈；极矮横屏按金额实际位置限制键盘高度，内部滚动，保留按键尺寸。 |

没有迁移存储键、图标编号、类别名称、排序或隐藏项；未修改资金计算、关联规则、默认值、成功后继续记账、原生返回代码。以本轮开始的实际工作区为基准，35 项 JS/CSS 摘要核对仅以上三个生产文件改变；`index.html` 与开始快照一致。原有未提交改动保留。
