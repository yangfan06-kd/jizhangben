# 首页信息结构调整（2026-10-15）

## 最终行为

根据用户本轮连续反馈，首页顺序为：原位置的账户／报表／预算／基金入口、本月概览、紧凑最近流水、本月趋势、期间收支入口。删除原“账本总收支”标题，首页没有折叠区。底栏仍是流水、居中记一笔、设置。

月度概览保留结余、支出、收入、净资产及小眼睛；趋势直接展示，刻度增大并为长轴标签预留空间，过大刻度以万／亿缩写，完整交易金额不缩写。最近五笔按日期和同日编号倒序、按完整日期分组；原记录数组不被排序，最多保留五个内存候选，不建立新的账本存储。图标继续读取现有类别映射，金额复用 `amountText`，保留负收入及基金／转账／押金等中性本金的显示口径。

普通字号下最近流水由约 60px 降为约 46px；最小点击高度 44px，账户主行 13px、类别／类型 12px、金额 14px、图标 20px。大字和长名称时自然增高，不通过裁掉金额保持固定尺寸。点击一笔进入当天流水，“查看全部”进入所有日期的流水，编辑删除仍在原明细页处理。

四个期间汇总移到独立、无外框的“期间收支”页，保留今天、本周、本月、本年及负债；负债标签带期间名称。首页期间与最近流水不受明细页遗留的筛选影响。通过首页明确选择日期／期间时，会清除内存中的账户、类别和搜索条件，以展示该范围完整流水；不写入用户账本或类别设置。原生返回仍沿用专项页回首页的行为。
