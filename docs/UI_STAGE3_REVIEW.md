## 发现的问题

初轮在保存失败提示处超时：原确认层 1000 低于编辑层 1100，提示按钮被挡住，已仅在编辑开启时提高层级。全局按钮样式还隐藏了取消键，已用局部规则修复，未用强制点击绕过。

快速鼠标脚本跨操作的计时未满足预期，改用同一事件循环的合成触摸核实早期移动分支；不把它当作真实触屏滚动证据。位置恢复改为离开时同步捕获、进入时固定恢复值，增加回归；固定 80ms 等待与实际绘制帧的结果分开保留。
