## 本轮重点：金额键盘与小屏

优先采用不保存的记账草稿检查，不改已有流水、类别、账户或密码。若需验证保存，请使用单独的测试账本。

先不要点击金额键盘的“确定”，它会直接保存当前账目；只有进行下面单独的保存检查时才点击。

| 操作 | 预期 |
| --- | --- |
| 进入“记一笔”，输入 `12+3` | 大金额为 15，下方显示计算式；没有自动提交 |
| 收起键盘，再点“输入金额” | 15 和未确认的 `12+3` 都保留，页面没有残留键盘的大块空白 |
| 点击备注并输入文字 | 自定义金额键盘收起，系统输入法可用，原金额保留 |
| 切换普通记账类型 | 键盘按既有规则出现，类型字段正确，没有产生新流水 |
| 打开账户资金修改，先点本金、再点余额 | 两个字段各自显示自己的金额，计算式不会串到另一字段 |
| 使用系统较大字号，再旋转手机或使用小窗口 | 返回入口仍能访问；键盘过高时可内部滚动到“确定”，表单可滚动到最下方字段 |
| 打开隐私小眼睛 | 金额仍被遮挡，键盘和返回可以正常使用 |
| 返回首页，再进入记一笔 | 页面、金额和草稿行为符合原规则，不自动保存或重复记账 |
| 测试账本内填完类别、账户和日期，输入 `12+3`，点击“确定” | 只新增一笔 15 元记录，不用再点“保存这笔账”；继续停留在记账页，流水可查到新记录 |

若软件锁定竖屏，不要求强制改变设备方向；可通过实际较小窗口或隔离浏览器检查短屏布局。浏览器放大不是 Android 系统字号验证。
