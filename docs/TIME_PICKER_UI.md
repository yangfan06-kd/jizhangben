# 记账页时间选择（应用内滚轮）

记录日期：2026-11-20
范围：只改「记一笔 / 修改账目」里的时间字段，其他交互不动。

## 现在的行为

- 时间字段默认显示**当前时间**（打开记账页时计算），不再弹系统时钟表盘；排布上「备注」单独一行，**日期与时间左右并排**，与效果图一致。
- 点「时间」这一行 → 底部弹出滚轮弹层：小时 0–23、分钟 0–59，默认停在当前时刻；上下滑动选择，点「确定」写入字段，点「取消」或点空白处不改。
- 新建账目：不点时间也能直接保存，保存时仍按**保存那一刻**记录（沿用原有 `留空=现在` 语义）。
- 编辑旧账目：原来没有时间时显示「未记录」；选过时间就按所选保存，不选则保持未记录。
- 未保存草稿会继续记住所选时间（草稿字段仍是 `recordTime`）。
- 基金/退休金等页面里的时间输入（`fundRecordTime`）不在本次范围，仍是系统时间选择。

## 没有改动的部分

- 类别：整行点击打开「选择类别」底部弹层（带图标的类别网格 + 自定义类别系统入口）。
- 账户：整行点击原地展开下拉；转账时「转入账户」同款。
- 类型横向 chips、金额自定义数字键盘、备注输入、原生日期选择。
- 保存/校验、草稿、备份恢复、账本存储格式、安卓更新提醒逻辑。

## 涉及文件

| 文件 | 改动 |
| --- | --- |
| `index.html` | 时间字段改成按钮 + 隐藏 input（`recordTime`），新增 `#timePickerOverlay` 滚轮弹层 |
| `js/record-form.js` | 时间显示同步、滚轮构建/滚动/确认/取消、打开前按当前值定位 |
| `js/record-draft.js` | 草稿恢复后同步时间显示 |
| `js/app.js` | 启动时绑定时间选择事件 |
| `css/style.css` | 时间字段、弹层、滚轮的样式 |
| `tests/time-picker.test.cjs` | 默认显示当前时间 / 编辑未记录 / 滚轮索引换算 |

`#recordTime` 仍然是隐藏 input，保存、草稿和既有测试都按原字段读取，不需要改数据格式。
