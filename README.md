# 记账本（jizhangben）

一个纯前端的网页记账本，用 HTML + CSS + JavaScript 写成，数据保存在浏览器本地，无需后端、无需安装任何东西，打开网页就能用。

## 功能特性

### 账户管理
- 账户分两大类：**资金账户**（现金、银行卡、支付宝、微信等）和**负债账户**（信用卡、花呗、京东白条等）
- 账户可自由添加、改名、删除
- 每个账户可设置「本金」（初始余额），之后随时修改
- 自动计算每个账户的当前余额，以及**净资产 = 资金账户总额 − 负债账户欠款**

### 记账
- 9 种类型：支出、收入、转账、余额、借贷、代付、报销、退款、押金
- 押金支持 4 个方向，自动归入收入或支出侧：
  - 主动收 → 收入增加
  - 我退给别人 → 收入减少
  - 主动付给别人 → 支出增加
  - 别人退回 → 支出减少（退款）

### 明细与统计
- 明细按时间段（从 / 到日期）、账户、类别自由筛选
- 显示所选阶段的**总收入、总支出、新增负债**
- 统计图：**柱形 / 扇形** 两种样式，**支出 / 收入 / 综合** 三种口径，每项带金额和占比百分比
- 收入用红色、支出用绿色（中国传统「红涨绿跌」）

## 技术栈

- 纯 HTML + CSS + JavaScript，全部写在单个 `index.html` 里
- 无框架、无构建工具、无第三方依赖
- 使用 `localStorage` 本地存储，关掉浏览器数据也不丢

## 使用方法

1. 下载或克隆本项目到本地
2. 直接用浏览器打开 `index.html` 即可，无需安装或配置任何环境
3. 数据存在当前浏览器的本地存储里，换浏览器或清除浏览器数据会丢失账目
