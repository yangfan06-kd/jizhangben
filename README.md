# 简簿（jizhangben）

一款中文个人记账项目，提供可离线使用的 Android App，也提供 iPhone PWA 和电脑浏览器版。项目从原有的 HTML、CSS 和 JavaScript 网页逐步发展，包含本地记账、数据备份、基金记录和可选的 FastAPI 服务端。

## 下载与使用

- **Android v2.18**（版本号 119）。[正式下载页](https://jizhangben-download.pages.dev/) · [GitHub 备用 APK](releases/jizhangben-v2.18.apk)
- **iPhone**。用 Safari 打开后添加到主屏幕。已添加的用户可从「设置 → 应用与更新」检查新版。[iPhone 入口](https://jizhangben-iphone-test-2026.pages.dev/)

Android 安装包沿用 com.jizhangben.app 和正式签名。更新前可导出 JSON 备份，随后打开 APK 覆盖安装。应用内的下载提醒见 [应用内更新说明](docs/ANDROID_IN_APP_UPDATE.md)。

## 主要功能

- 多账本和账户管理，记录账户余额、负债和净资产。
- 支出、收入、转账、押金、借贷、代付、报销和退款等记录；押金本金与损益分开处理，并支持关联结算。
- 离线记账允许负收入作为收入冲减，减少收入合计和所选账户余额；记完一笔后留在记账页，方便继续记录。
- 收入与支出类别分别维护；读取旧类别时保留原有的大类、小类、顺序、图标与隐藏设置。支出类别改名沿用同步旧流水的规则；收入类别改名只影响之后的选择，旧流水仍显示原名称。
- 记录列表支持按月、按年、日期、账户和类别筛选，也可以搜索备注；筛选结果显示收入、支出和笔数。
- 按天、周、月和年查看收支，配有统计图和预算管理。
- 基金定投和单笔投资使用独立基金账户；记录追加、到期记账和赎回结算。
- 在“记一笔”顶部进入退休金固收设置，可设定每月到账日和账户；应用关闭期间错过的收入会在下次打开时按原日期补记。修改计划不改写已生成的流水，升级类别目录也不会覆盖历史账目。
- 可选开启本机六位密码、验证后记住此手机免输密码，并在设置中取消免输、修改或关闭密码；隐私小眼睛可将金额遮成星号。本机密码用于应用入口保护，不代表账本数据加密。
- 导出与导入本地 JSON 备份；支持整理外部记账 CSV 后导入。
- 内置金额键盘支持加减计算；切换记账主类型后可直接继续输入金额。

## 数据与离线使用

个人离线 App 无需注册、服务器、Docker、USB 或移动网络。账目保存在安装它的手机本地，备份文件可以用于换机迁移。另一台设备不会自动看到本机数据。

Android 使用原生 SQLite 事务保存；尚未改动的旧存储仍兼容读取，备份格式不变。浏览器版继续使用当前浏览器的本地存储。应用入口密码不代表数据已经加密，请妥善保存包含个人账目的备份文件。

覆盖安装同一包名、同一签名且版本号更高的 APK，会保留 App 的本地存储。卸载 App 或清除 App 数据会移除本地账本，因此更新时直接打开新版 APK 进行安装。

## 在电脑上使用

无需配置环境，可以直接用浏览器打开 `index.html`。这种方式把数据存在当前浏览器的本地存储中。若要使用可选服务端登录和跨设备同步，请参考 [部署说明](docs/DEPLOYMENT.md)；服务端模式需要自行运行后端。

## 开发与构建

技术栈：HTML、CSS、原生 JavaScript、Capacitor、Node.js；可选后端为 FastAPI 和 SQLite。

安装前端依赖并运行自动检查：

```powershell
npm install
npm test
```

构建个人离线 Android APK 需要 Java 21、Android SDK 和 Android Build Tools：

```powershell
npm run app:build:offline
```

APK 会生成在 `android/app/build/outputs/apk/debug/app-debug.apk`。每次准备更新都需要增加 Android `versionCode`，并保留相同应用包名和签名证书，才能覆盖安装并保留应用数据。当前发布版本和签名摘要记录在 [Android 版本基线](docs/RELEASE_BASELINE.md)。

启动 Docker Compose 服务端：

```powershell
docker compose up --build -d
```

手机需要连接与电脑相同的 Wi-Fi 才能访问电脑局域网地址。服务端部署、持久化和公网 HTTPS 配置见 [部署说明](docs/DEPLOYMENT.md)。
