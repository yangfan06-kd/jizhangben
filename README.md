# 记账本（jizhangben）

一个正在从纯前端工具逐步升级为全栈应用的网页记账本。当前可用功能仍由 HTML、CSS、JavaScript 和浏览器本地数据提供；前端工程化与本地数据稳定化已经完成，FastAPI + SQLite 后端正在按版本迁移逐步建设。

## 功能特性

### 多账本
- 支持多个账本，比如「我的账」「孩子的账」，每个账本有自己的名称和分类标签（都可自定义）
- 顶部下拉框按分类切换账本，账本可新建、改名、删除
- 每个账本的账户和账目各自独立、互不干扰，但格式完全一致
- 「总览」页一眼看所有账本的净资产和本月收支，底部给出合计
- 新建或改名账本时若有同名会红色提醒（不禁止保存）

### 账户管理
- 账户分两大类：**资金账户**（现金、银行卡、支付宝、微信等）和**负债账户**（信用卡、花呗、京东白条等）
- 账户可自由添加、改名、删除
- 每个账户可设置「本金」（初始余额），之后随时修改
- 自动计算每个账户的当前余额，以及**净资产 = 资金账户总额 − 负债账户欠款**

### 记账
- 类型：内置 9 种（支出、收入、转账、余额、借贷、代付、报销、退款、押金），还可自定义类型，并选「算收入 / 算支出 / 中性」
- 类别同样可自定义；类型、类别太多时默认折叠，点一下展开
- 押金支持 4 个方向和原押金关联：
  - 收取或支付押金时只记录资金流，不直接计入收入或支出
  - 全额退回时收入和支出都保持为 0
  - 最终结算少退的部分，根据原押金方向计入收入或支出

### 明细与统计
- 明细按时间段（从 / 到日期）、账户、类别自由筛选，另有关键字搜索（备注 / 类别 / 类型）
- 明细列表默认收起，点「展开明细」才显示，避免一长串
- 显示所选阶段的**总收入、总支出、新增负债**
- 统计图：**柱形 / 扇形** 两种样式，**支出 / 收入 / 综合** 三种口径，每项带金额和占比百分比
- 收入用红色、支出用绿色（中国传统「红涨绿跌」）

### 数据备份
- 「管理」页底部提供「导出备份」，把所有账本和账目打包成一个 JSON 文件下载
- 「导入备份」选回该文件即可恢复（会覆盖现有数据，导入前有确认提示）
- 换电脑、换浏览器或误清缓存时，靠它找回数据

## 技术栈

- HTML + CSS + 原生 JavaScript，按功能拆分模块
- `localStorage` 存储适配、schema 版本迁移和 JSON 备份
- Node.js 内置测试运行器，目前不依赖第三方前端库
- FastAPI + SQLite 后端可以运行，数据库 schema v5 已建立用户、账本、账户、类别、记账类型、账目和登录会话表
- 已增加注册、登录、退出和当前用户接口；密码使用 PBKDF2 哈希，会话通过 HttpOnly Cookie 保存
- 网页已提供登录/注册面板；登录用户会按会话读取自己的服务端账本，无登录 Cookie 时暂时保留本地开发兼容模式
- 账目服务层会在事务内校验用户归属、账本账户、类型行为和押金对应关系
- 后端启动时会幂等建立本地开发用户，已支持账本和账本内账户的查询、新建 API
- 已支持修改、删除账本；删除账本会同步清理其账户和账目
- 已支持读取和新建当前用户的自定义类别、记账类型，供记账表单逐步改用服务端选项
- 已支持修改自定义类别和记账类型名称，以及归档选项并保留历史账目引用
- 已支持按日期、账户、类别和关键词筛选账本内账目，返回类型、类别和账户显示信息
- 已支持 `/api/overview` 返回各账本账户余额、期间收支和净资产合计，押金与负债口径和前端保持一致
- 已支持服务端 JSON 备份导出和事务式导入，导入时自动重建账本、账户、选项、账目及押金关联
- 已支持服务端只读迁移预览，导入前可先查看数量、支出和净资产对账结果
- 网页账本管理已提供迁移预览卡片；确认后才导入服务端，原浏览器本地备份继续保留
- HTTP 页面中新建账本、账户和账目会优先写入服务端；普通账目、转账和押金使用同一套后端校验，服务端不可用时自动恢复本地流程并提示用户
- 账目保存期间会阻止重复提交；服务端业务冲突会保留表单提示修正，网络失败才回退到本地
- 网页已增加可选后端读取层：在 HTTP 环境尝试读取服务端账本、账户、类别、记账类型、当前账本明细和总览，直接打开文件或请求失败时自动回退到 localStorage；新建账本、账户和账目优先写入服务端，账本、账户和账目修改与删除也优先写入服务端，网络失败时再回退本地
- 已支持安全删除账目；已有关联退回记录的原押金会受到保护，避免破坏押金对账
- 已支持完整修改普通账目，并重新校验账户、类别、类型与押金规则
- 第一个业务接口 `POST /api/books/{book_id}/records` 已支持创建普通账目、转账和押金关联

## 使用方法

1. 下载或克隆本项目到本地
2. 直接用浏览器打开 `index.html` 即可，无需安装或配置任何环境；此时使用 localStorage。本地联调后端时，再通过 HTTP 页面并配置 API 地址
3. 数据存在当前浏览器的本地存储里，换浏览器或清除浏览器数据会丢失所有账本和账目，建议定期用「导出备份」留个底

通过 HTTP 打开页面时，读取层默认请求同源的 `/api`；如果前端和后端使用不同端口，可在加载入口脚本前设置 `window.JIZHANGBEN_API_BASE_URL`，例如 `http://127.0.0.1:8000/api`。当前阶段新建账本、账户和账目会优先写入服务端；账本、账户和账目修改与删除也优先使用服务端接口，网络异常时恢复浏览器本地快照后继续操作。
